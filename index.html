Cách 1 — Load unpacked

Đơn giản nhất, không cần quyền quản trị. Bản cài theo cách này không tự cập nhật: mỗi bản mới phải tải và nạp lại.

  1. Tải bản .zip ở trên và giải nén ra một thư mục cố định.
  2. Mở edge://extensions hoặc brave://extensions.
  3. Bật Developer mode, chọn Load unpacked, trỏ vào thư mục vừa giải nén.

Cách 2 — Cài qua policy, tự cập nhật

Trình duyệt sẽ tự tải bản mới mỗi khi trang này công bố phiên bản mới. Chạy trong PowerShell với quyền Administrator, rồi khởi động lại trình duyệt:

$entry = 'aaomhjfkeodmbdafcddjppbeomiplleg;https://nguyenquocanhz.github.io/uBlock-mv3/update.xml'
foreach ($k in 'HKLM:\SOFTWARE\Policies\Microsoft\Edge\ExtensionInstallForcelist',
              'HKLM:\SOFTWARE\Policies\BraveSoftware\Brave\ExtensionInstallForcelist') {
  if (-not (Test-Path $k)) { New-Item -Path $k -Force | Out-Null }
  $existing = (Get-Item $k).Property | ForEach-Object { (Get-ItemProperty $k).$_ }
  if ($existing -notcontains $entry) {
    $n = 1; while ((Get-Item $k).Property -contains "$n") { $n++ }
    New-ItemProperty -Path $k -Name "$n" -Value $entry -PropertyType String | Out-Null
  }
}

Lệnh chỉ thêm một mục, không xoá các extension bạn đã cấu hình sẵn bằng policy. Để gỡ:

$entry = 'aaomhjfkeodmbdafcddjppbeomiplleg;https://nguyenquocanhz.github.io/uBlock-mv3/update.xml'
foreach ($k in 'HKLM:\SOFTWARE\Policies\Microsoft\Edge\ExtensionInstallForcelist',
              'HKLM:\SOFTWARE\Policies\BraveSoftware\Brave\ExtensionInstallForcelist') {
  if (Test-Path $k) {
    (Get-Item $k).Property | Where-Object { (Get-ItemProperty $k).$_ -eq $entry } |
      ForEach-Object { Remove-ItemProperty -Path $k -Name $_ }
  }
}
Chỉ chạy lệnh này trên máy của chính bạn. Extension cài qua policy không gỡ được từ giao diện trình duyệt, và trình duyệt sẽ hiện dòng "Managed by your organization". Đó là hành vi bình thường của policy.

Vì sao không kéo thả file .crx?

Edge và Brave, như mọi trình duyệt Chromium, từ chối file .crx không đến từ store chính thức, và trang web đã mất quyền tự cài extension từ Chrome 71. Hai cách ở trên là hai đường cài được thật sự ngoài store.
